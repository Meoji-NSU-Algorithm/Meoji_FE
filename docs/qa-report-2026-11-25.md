# QA 보고서 2026-11-25 — 휴대폰(768px 미만) 전용 화면

대상 브랜치 `feat/mobile-redesign` (origin/main 기반). Figma "NOL 스타일 리디자인" 중 모바일 전용 섹션(node 712:2019, 42보드)을 휴대폰 화면으로 교체했다. 768px 이상은 기존 PC 화면 그대로다.

## 환경과 방법
- BE: 로컬 `Meoji_BE`(5000번), FE: Vite 5173번(카카오 지도는 이 포트에서만 로드).
- 브라우저: Playwright + 시스템 Chrome, 390×844(2배율·터치). 로그인 후 화면은 **사용자가 직접 카카오 로그인**한 세션을 임시 폴더에 저장해 사용했고 보고서 작성 후 삭제했다.
- 역할별 서브에이전트: 개발(공통 레이어, 화면 4그룹, 공유 컴포넌트 통합, 버그·디자인 수정), 테스트, 디자인 검수 2회(로그인 전·후), QA(흐름).
- 자동 검사: Vitest 503개, `tsc -b`, oxlint, `vite build` 통과.

## 외부 호출과 쓰기
- 외부 API: 길찾기 **대중교통 1회**(`/api/directions`). 자동차·도보와 그 밖의 외부 호출 없음.
- 쓰기: 찜 추가·해제와 되돌리기만. 시작 0건 → 종료 0건으로 복구. 리뷰·프로필·사진 업로드·탈퇴는 하지 않았다.

## 발견한 결함과 처리
테스트 단계(6건, 모두 수정): 겹친 시트 닫을 때 스크롤 잠금 남음(높음), ESC 한 번에 겹친 시트 전부 닫힘, `viewport-fit=cover` 누락, 약관 하단 바 토스트 위치, 시트 포커스 트랩, 데스크톱 /search 불필요 요청.
디자인 검수(Figma 대비): 홈 섹션 제목 줄 44→29px, 검색 칩 44→32px, 로그인·404 줄 높이, 페이지 제목 줄 높이 68.5→62px, 무료 카드 232→251px, 필터 시트 높이 642→748px, 리뷰 별점 터치 영역 13×26→13×44(모양 그대로) 등을 실제 Chrome 재측정으로 맞췄다.

남은 것(이번 작업 범위 밖):
- 목록 페이지 번호를 눌러도 맨 위로 올라가지 않는다. **main에도 원래 없는 동작**(`Pagination`에 스크롤 처리 없음).
- 홈 태그 기획전이 8장(Figma 10장): "가족"·"음악" 태그 행사가 0건이라 기존 숨김 규칙에 걸림. 데이터가 생기면 10장.
- 지도 초기 전국 줌에서 가격 핀이 겹쳐 터치로 고르기 어렵다.
- 리뷰 작성 중 뒤로 가면 확인 없이 나간다(Figma S12는 수정 시트용).

## 확인하지 못한 것
- 길찾기 자동차·도보(S15), 경로 없음(S14): 외부 API 보호로 열지 않음. 단위 테스트로 대체.
- 리뷰 목록·사진 크게 보기·수정 시트·삭제 확인(S9~S12), 리뷰 있는 상세: 로컬 DB에 리뷰가 없고 사용자 허락 없이 쓰지 않음.
- 사진 없는 상세(S8), 로그인 처리 중(M8-2), 위치 허용 상태의 내 위치, 네이티브 공유 시트, 실기기(iOS safe-area 등).
- 프로필·사진 업로드·탈퇴 제출.
