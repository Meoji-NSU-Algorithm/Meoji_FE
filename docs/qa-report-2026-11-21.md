### 상세 500의 원인

BE 로그: `RuntimeError: You must call @jwt_required() or verify_jwt_in_request() before using this method`, 위치 `app/domains/events/routes.py` `get_event`의 `user_id=int(get_jwt_identity())`.
`@jwt_required()`가 `@events_bp.get("/<int:event_id>")`보다 **위**에 있어서, Flask에는 인증 래퍼가 없는 원래 함수가 등록된다. 아래처럼 순서를 되돌리면 된다(앞의 11/20 F1 마이그레이션 500과는 다른 원인).

```
@events_bp.get("/<int:event_id>")
@jwt_required()
def get_event(event_id):
```
