## 브라우저 E2E

완료:
- 홈
- 목록 + 필터 (`?category_id=2&sido_code=11&is_free=true` -> 3건, API 결과와 일치), 정렬, 검색
- 상세
- 찜 추가/해제
- 리뷰 작성(사진 포함)/수정/삭제
- 캘린더, 지도, 프로필
- 404 페이지
- 존재하지 않는 행사 오류 상태
- 길찾기 오류 상태
- 회원 탈퇴

미완료:
- 실제 카카오 로그인/콜백
- 모바일 뷰포트
- 브라우저에서의 만료 토큰 자동 갱신 (API 수준은 검증됨)
- 배포 환경 (CORS, 이미지 HTTPS): 배포 시 확인
- 스크린샷은 일부만 육안 확인
