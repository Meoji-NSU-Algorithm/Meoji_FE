# 디자인 요청 사항

Figma 파일 `tYosRvCIkNKKUxiefyGrbZ`, 캔버스 'NOL 스타일 리디자인' (node 378:2019). 디자인은 프론트에서 임의로 바꾸지 않으므로, 아래 항목은 디자이너가 Figma에서 수정하거나 결정해야 한다. 발표용 MVP 기준이다.

## 이번 라운드에 이미 Figma에 맞춘 항목 (다시 작업하지 않아도 됨)

헤더 활성 탭, C3 토스트 문구, C4 리뷰 없음 블록, D3 보조 문구, E2 빈 상태, E8/E9 문구, C2 찜 추가 토스트와 '보러 가기', A1/B1 작은 무료 카드, B1 분류 알약, C1 메타 줄 아이콘.

확인 요청: 하트 타일 크기(24px)와 E2 의 CTA 크기는 스크린샷으로 추정한 값이다. 실제 값과 맞는지 확인해 달라.

## 프레임별 요청

### E5·E6·E7 프로필 편집 / 사진 변경 / 저장 알림
- **문제**: 프로필 편집 화면이 디자인에 있으나 구현 불가
- **이유**: BE에 프로필 수정 API가 없다 (`/users/me` 는 GET/DELETE 만).
- **현재 FE**: 읽기 전용 프로필 ('내 프로필', 뒤로/로그아웃). E1 버튼은 '프로필 편집' 대신 '프로필 보기'. F2 '프로필을 저장했어요!' 토스트는 쓰지 않는다.
- **요청**: 읽기 전용 프로필로 재디자인하거나, 기능을 보류하기로 확정해 달라.

### E4 리뷰 삭제
- **문제**: 디자인에는 토스트만 있다.
- **현재 FE**: 삭제 전 확인 모달 ('리뷰를 삭제할까요?')을 둔다. 리뷰 수정 모달도 프레임이 없다.
- **요청**: 확인 모달을 디자인에 추가할지 결정 (파괴적 동작이라 추가 권장). 리뷰 수정 모달 프레임 추가.

### C5 vs C1 사진 없음
- **문제**: C5 는 회색 단색 히어로 + 이미지 아이콘 + '등록된 사진이 없어요'. B1 카드의 사진 없음 자리표시도 다르다.
- **현재 FE**: 축제 그라데이션 + 시·도 + 제목 오버레이.
- **요청**: 어느 쪽이 기준인지 확정.

### D1 길찾기 / D2 / D3
- **문제 (D1)**: 디자인은 모든 이동수단 탭에 소요 시간을 보여주나, API는 호출당 한 가지 모드만 반환한다.
- **현재 FE**: 선택하지 않은 탭은 '-'. 디자인에 없는 FE 추가 요소: 단계 유형 라벨, 5단계 이후 '전체 N단계 보기' 접기, 지도 캡션 '실제 경로선은 준비 중이에요…', 도착 라벨 'HH:MM 출발 · 도착 예정'.
- **D2**: 디자인은 실시간 결과, FE는 Enter 후 결과 표시.
- **D3**: 보조 문구는 디자인대로 구현됨.
- **요청**: D1 에 위 상태(미선택 탭, 단계 접기, 지도 캡션)를 반영하고 D2 동작을 확정.

### A7 약관
- **문제**: FE에 선택 행 '[선택] 마케팅 정보 수신 동의' 추가 (BE 동의 API가 marketing 지원). 부제 문구가 다르다. '보기' 버튼의 이동 대상이 없다 (약관/개인정보 화면 디자인 없음). 디자인은 전체 선택 상태, FE는 미선택으로 시작.
- **요청**: 약관·개인정보 상세 보기 화면 디자인, 마케팅 행 채택 여부와 초기 체크 상태 결정.

### A2·A3 로그인 문구
- **문제**: 하단 문구 디자인 '로그인하면 이용약관 및 개인정보처리방침에 동의한 것으로 봐요.' vs FE '로그인 후 …동의 절차가 이어져요.' (로그인 뒤 동의 단계가 있음). 통계 '17 전국 시·도' vs FE 16 (데이터 기준). 첫 통계는 실제 total_count.
- **요청**: 문구를 동의 절차에 맞게 수정, 시·도 수 확인.

### A8 홈 (로그인 후)
- **문제**: 개인 히어로 배너 '{닉네임}님의 캘린더 / 이번 주에 찜한 행사가 N개' 미구현 (찜 기반 로직 필요). eyebrow '충남 천안' 은 시·군·구가 필요한데 카드에 없다.
- **현재 FE**: 다음 히어로 행사를 표시.
- **요청**: MVP 이후 항목으로 표시. 디자이너가 원하면 알려 달라.

### A1·B1 카드
- **문제**: 평점 '★ 4.7 (128)' 과 태그는 BE 필드에 의존한다. 카드 응답에 없어 숨긴다.
- **요청**: 평점 없는 카드 상태를 기본으로 제공. 무료 카테고리 아이콘(A1 스트립)은 직접 그린 SVG라 Figma 원본을 추출할 수 없으니 에셋 제공. 홈 '돈 안 드는 주말' 섹션 카드에는 A1 처럼 사진 '무료' 배지가 그대로 있다.

### B4 지도
- **문제**: 디자인은 첫 목록 항목 선택 + 검정 핀 + 말풍선 마커. FE는 선택 없이 시작하고 알약 마커.
- **현재 FE 추가**: '상세 보기 ›' 링크, '위치를 찾지 못한 행사 N개…' 안내.
- **요청**: 위 상태를 디자인에 반영.

### B2 / B6
- 헤더 검색창이 쿼리를 반영한다. B6 에서는 FE가 오류 위에 필터 패널도 표시한다. 디자인 확인 요청.

### 푸터 링크
- `/about`, `/terms`, `/privacy`, `/contact` 대상 화면 디자인이 없어 현재 404 페이지로 이동한다.
- 요청: 화면 디자인 또는 링크 제거 결정.

### 공통: 찜 해제 토스트
- 상세 페이지의 '찜을 해제했어요' + '되돌리기' 에서 되돌리기 동작이 없다 (내 찜 목록에만 있음). 카드에서도 이제 해제 토스트가 나온다 (FE 통일).
- 요청: 상세·카드에서의 되돌리기 포함 여부 결정.
