# 디자인 요청 사항

Figma "NOL 스타일 리디자인"(`tYosRvCIkNKKUxiefyGrbZ`, node `378:2019`)과 백엔드 develop(235c500)의 실제 데이터가 맞지 않거나, 디자인에 없는 상태를 프론트가 임시로 만든 부분입니다. **프론트는 디자인을 새로 만들지 않고 임시 처리만 했습니다.** 디자인 확정 후 알려 주시면 반영합니다.

> 확인 범위: Figma의 텍스트와 화면을 백엔드 코드와 대조해 정리했습니다(카드 `★ 4.7 (128) · 조회 3.2만`, A2/A3, A7, D1, E1, E5, E8, E9). 리뷰 사진, 길찾기 오류 등 "시안에 없는 상태"는 직접 확인이 아니라 시안에 없다는 점을 기준으로 적었습니다.

## C. 디자인에 없는 상태 (프론트가 임시로 만듦)

**리뷰 사진 (C1, C3, C5, E3 관련)**
- 사진 업로드 중, 업로드 실패, 5장 초과, 형식·용량 오류(jpg/png/webp, 10MB) 상태
- 첨부한 사진 썸네일 + 삭제(×) 버튼, 첨부 개수(`n/5`) 표시 — 임시: 64px 썸네일, 버튼 라벨 `사진 추가 (n/5)`
- 리뷰 사진을 눌렀을 때의 확대 보기 — 임시: 일반 모달에 이미지만, 갤러리 이동·닫기 디자인 없음
- 리뷰 작성자 사진이 깨졌을 때의 대체 이미지
- 사진 업로드 시간이 지나 새 사진이 비워질 때의 안내(현재 폼 하단 오류 문구), 미첨부 사진 한도(20장) 초과 안내

**길찾기 (D1~D3)**
- 상태: 경로 불러오기 실패(502/504) 재시도 화면. D3는 "경로 없음"만 있음
- 단계가 많을 때(자동차) 5개만 보이고 "전체 N단계 보기 / 접기"로 펼치는 UI — 임시로 텍스트 버튼과 내부 스크롤로 구현
- 지도 하단 안내 "실제 경로선은 준비 중이에요. 출발지와 도착지만 표시돼요." — 경로 좌표가 생기면 삭제
- step 종류별(지하철·버스·도보·자동차·기타) 아이콘과 라벨
- 도착 예정 시각과 출발 시각 표기

**찜·공통**
- 찜 추가/해제 실패 시 토스트 (F2 완료 알림 모음에 실패 알림 없음)
- 지도: 좌표가 없는 행사 N개 안내 문구(현재 "위치를 찾지 못한 행사 N개는 지도에 표시되지 않아요"), 100개 초과 시 안내
- 서버 장애(503)·네트워크 오류 등 공통 에러 문구 톤
