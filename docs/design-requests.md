## 미해결 요청 상세

### DR1. C2 리뷰 사진 사진별 업로드 상태 (구 DR4)
- **문제**: 시안의 사진별 '업로드 중', '다시 시도', 시간 초과('시간이 지나 올려 둔 사진이 비워졌어요'), 미등록 사진 20장 한도, '업로드가 끝나면 등록할 수 있어요'는 현재 BE 구조(사진을 리뷰 등록 요청에 함께 multipart로 전송, 사전 업로드 API 없음)상 만들 수 없어 구현하지 않았다.
- **현재 FE**: '등록 중…' 단일 상태 + 5장/10MB/형식 안내.
- **요청**: 이 상태 기준으로 다시 그리거나, BE 구조 변경 여부를 결정해 달라.

### DR2. 리뷰 글자 수 500 vs 1000 (구 DR5)
- **문제**: 시안은 n/500, BE는 1~1000자를 허용한다.
- **현재 FE**: 1000으로 구현 (500자 초과 기존 리뷰의 수정을 막을 수 없어서).
- **요청**: 시안을 1000으로 맞추거나 BE 제한 변경을 결정해 달라.

### DR3. 기획전 태그 교체 (구 DR24)
- **문제**: BE는 고정 사전(불꽃놀이, 푸드트럭, 야간, 체험, 가족, 공연, 전시, 음악, 꽃, 먹거리)으로만 태그를 만든다. 시안의 #야시장, #반려동물, #아이와함께, #단풍은 항상 결과가 0건이다.
- **현재 FE**: 같은 그라데이션을 유지하고 임시 제목을 붙였다.

  | 기존 | 교체 | 임시 제목 |
  |---|---|---|
  | #야시장 | #야간 | 퇴근 후 밤 나들이 |
  | #반려동물 | #음악 | 음악이 흐르는 주말 |
  | #아이와함께 | #가족 | 주말 가족 나들이 |
  | #단풍 | #꽃 | 꽃 보러 가는 길 |
  | #불꽃놀이 | #체험 | 직접 해 보는 체험 |

- **2026-11-21 변경**: #불꽃놀이는 행사가 0건이라 FE가 같은 날 #체험('직접 해 보는 체험')으로 교체했다. #푸드트럭은 그대로다.
- **현재 태그별 결과 수 (개발 DB 2026-11-21 기준)**: 푸드트럭 1, 체험 40, 야간 7, 음악 3, 가족 11, 꽃 3.
- **요청**: 최종 태그·제목·색을 정해 달라. 데이터 수가 충분한 태그(체험 40, 가족 11 등)를 고려해 달라. 사전에 없는 태그는 BE 사전 추가가 필요하다.

### DR4. A1 '태그로 찾는 기획전' 카드 내용 (구 DR23)
- **문제**: Figma A1 (node 408:1115, 프레임 408:2)은 기획전 카드 6장을 그라데이션 + 흐릿한 빛 원 + #태그 칩 + 제목 + '행사 모아보기 ›'로만 그렸고, 이미지 레이어가 없다. FE는 그라데이션만 표시하고 빛 원은 그리지 않아 단색처럼 보인다.
- **요청**: 카드 안에 사진·일러스트를 넣어야 하는지, 아니면 그라데이션 + 빛 원이 최종인지 확인해 달라. 사진이 필요하면 태그별 에셋을 제공해 달라.
- **현재 FE**: 답을 받을 때까지 시각 표현을 바꾸지 않았다.

### DR5. 리뷰 수정 모달 이탈 확인 (구 DR6)
- **문제**: 시안에는 메모('수정한 내용이 사라져요')만 있고 프레임이 없다.
- **현재 FE 임시 문구**: 제목 '수정한 내용이 사라져요', 본문 '닫으면 바꾼 내용이 저장되지 않아요.', 버튼 '계속 수정' / '닫기'.
- **요청**: 프레임 추가와 문구 확정.

### DR6. 푸터 문의 링크 숨김 (구 DR7)
- **문제**: 2차 프레임(593:2)에 '문의하기 -> mailto', '서비스 소개 -> /about(링크 빼기)'가 남아 있어, FE가 둘 다 뺀 현재 상태와 다르다.
- **요청**: 프레임을 정리하고, 팀 문의 메일 주소를 정해 달라. 주소가 정해지면 mailto 링크로 복구한다.

### DR7. A1 지역별 행사 기본 선택 '전체' (구 DR25)
- **변경**: 팀 결정으로 FE는 2026-11-20에 지역 칩의 기본 선택을 '충남'에서 '전체'로 바꿨다.
- **요청**: 프레임 408:2의 지역 칩에서 '충남'이 선택된 상태로 그려져 있다면 '전체'로 고쳐 달라 (프레임 내용은 열어 확인하지 않았다).

### DR8. 로그인 화면 '전국 시·도' 통계 (구 DR10)
- **문제**: 로그인 전에는 BE가 시·도 목록을 주지 않아 값을 받지 못했다. BE는 토큰 없이 200을 주도록 고쳤으나(`backend-requests.md` 구 B5) 아직 커밋 전이라 FE는 연결하지 않았다.
- **메모**: BE의 `/sidos` 공개 변경이 커밋되면 FE가 숫자를 표시한다. 시안의 17곳(세종 포함)과 데이터 기준이 다를 수 있다.
- **현재 FE**: '-' 표시.
- **요청**: 값을 받지 못했을 때의 모습(통계 숨김 등) 또는 고정 문구를 결정해 달라.
